# 🏡 Airbnb Listings & Reviews Dashboard

## 📖 Project Overview

This project presents an interactive **Power BI dashboard** built using the **Airbnb Listings & Reviews** dataset from Maven Analytics. The dashboard helps explore Airbnb listing performance, pricing trends, customer ratings, and host activity through interactive visualizations and DAX-based calculations.

The dashboard is designed to help users analyze Airbnb properties and identify trends across different locations, room types, pricing, and customer reviews.

---

## 📂 Dataset

**Source:** Maven Analytics Data Playground

https://mavenanalytics.io/data-playground/airbnb-listings-reviews

The dataset contains Airbnb listing information, including:

- Listing details
- Host information
- Property type
- Room type
- Price
- Availability
- Review ratings
- Number of reviews
- Location details

---

## 🎯 Project Objectives

- Analyze Airbnb listing performance.
- Compare pricing across different property types.
- Evaluate customer ratings and reviews.
- Monitor host activity and listing availability.
- Build an interactive dashboard for business analysis.

---

## 🛠️ Tools Used

- Microsoft Power BI
- DAX (Data Analysis Expressions)

---

## 📊 Dashboard Pages

### 1. Overview

The Overview page provides a high-level summary of Airbnb listings through KPI cards and interactive charts.

It includes:

- Overall listing statistics
- Key performance indicators (KPIs)
- Price trends
- Interactive filters
- Summary visuals

---

### 2. Ratings Analysis

The Ratings page focuses on customer feedback and property performance.

It includes:

- Review rating analysis
- Property comparison
- Rating distribution
- Listings by different categories
- Detailed comparison table

---

## 📈 DAX Measures

The dashboard uses DAX measures to calculate key business metrics, including:

- Total Listings
- Average Price
- Average Rating
- Total Reviews
- Other calculated KPIs used throughout the dashboard
